# Master Chat macOS icon

Generated with the built-in ImageGen tool. The PNG preserves transparency.
`icon.icns` contains standard macOS sizes from 16px to 1024px, including Retina.

Regenerate the ICNS from the PNG on macOS:

```sh
bash scripts/generate-mac-icon.sh
```

A refined macOS rounded-square tile in rich indigo blue (#5469da, matching the app UI) with subtle blue-violet depth and restrained soft highlights. Clean vector-like edges, mostly flat, no tiny details, no words, no lettering beyond the implicit M shape, no watermark, no extra objects, no border, no perspective.
